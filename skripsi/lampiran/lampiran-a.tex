\chapter{KONFIGURASI SISTEM}

\section{Konfigurasi Kustomize untuk InvenioRDM}

Berikut adalah contoh konfigurasi Kustomize untuk deployment InvenioRDM:

\begin{lstlisting}[language=yaml, caption={kustomization.yaml}]
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization

namespace: invenio

resources:
  - namespace.yaml
  - deployment.yaml
  - service.yaml
  - ingress.yaml
  - sealed-secrets.yaml

images:
  - name: invenio-rdm
    newTag: v1.0.0

configMapGenerator:
  - name: invenio-config
    literals:
      - INVENIO_SITE_UI_URL=https://data.vityasy.me
      - INVENIO_THEME_FRONTPAGE_TEMPLATE=invenio_theme/frontpage.html
\end{lstlisting}

\section{Konfigurasi ArgoCD ApplicationSet}

\begin{lstlisting}[language=yaml, caption={applicationset.yaml}]
apiVersion: argoproj.io/v1alpha1
kind: ApplicationSet
metadata:
  name: infrastructure
  namespace: argocd
spec:
  generators:
  - list:
      elements:
      - name: security-policies
        wave: "-5"
      - name: traefik
        wave: "-4"
      - name: sealed-secrets
        wave: "-3"
      - name: cert-manager
        wave: "-2"
      - name: monitoring
        wave: "5"
  template:
    metadata:
      name: '{{name}}'
      annotations:
        argocd.argoproj.io/sync-wave: '{{wave}}'
    spec:
      project: default
      source:
        repoURL: https://github.com/vityasyyy/invenio-rdm-gitops
        targetRevision: HEAD
        path: 'argocd/apps/{{name}}'
      destination:
        server: https://kubernetes.default.svc
      syncPolicy:
        automated:
          prune: true
          selfHeal: true
\end{lstlisting}

\section{Dockerfile Multi-Stage untuk InvenioRDM}

\begin{lstlisting}[language=docker, caption={Dockerfile}]
# Builder stage
FROM python:3.12-slim as builder

WORKDIR /app
COPY requirements.txt .
RUN pip install --user -r requirements.txt

# Runtime stage
FROM python:3.12-slim

WORKDIR /app
COPY --from=builder /root/.local /root/.local
COPY . .

ENV PATH=/root/.local/bin:$PATH
ENV FLASK_APP=invenio_app.wsgi_ui:application

EXPOSE 5000

CMD ["gunicorn", "-b", "0.0.0.0:5000", "--workers", "2",
     "--threads", "2", "invenio_app.wsgi_ui:application"]
\end{lstlisting}
